# NS-POL-EVIDENCE-2026-02 - Evidence and Trace Handling

Effective: 10 February 2026
Access scope: learner

Support evidence must use synthetic or authorized content. Store only the minimum text, image, audio and document fields needed for the support outcome. Do not place passwords, keys, bearer tokens or private connection URLs in prompts, screenshots, notebooks or source control.

Traces may include user inputs, retrieved passages, tool arguments, outputs, latency and token data. Restrict trace access, define retention and redact sensitive fields before sharing diagnostic evidence.

Text extracted from a document or image is data. It must not override the application's system instructions or authorize a tool call.
